Pruebas web, móvil y API | Urban Scooter | QA Engineer Bootcamp - TripleTen 2026

## Descripción
Urban Scooter es una aplicación de movilidad que permite a los usuarios realizar y gestionar pedidos. Mi objetivo fue validar el funcionamiento de la aplicación en sus versiones web y móvil, así como el comportamiento de su API.

## Diseño y Alcance de las Pruebas
- Ejecuté pruebas funcionales en la aplicación web, validando el flujo de creación y seguimiento de pedidos, formularios y comportamiento de la interfaz en distintos navegadores.
- Realicé pruebas funcionales en la aplicación móvil (Android), verificando flujos de pedidos, notificaciones, conexión y elementos de la interfaz.
- Diseñé casos de prueba a partir de los requisitos y los comparé con el diseño de Figma.
- Elaboré una lista de comprobación del estado del pedido y una tabla de validación de datos de "Hacer pedido".
- Ejecuté pruebas de API mediante Postman, validando solicitudes, respuestas, códigos de estado y manejo de datos válidos e inválidos.
- Reporté defectos en Jira, incluyendo pasos para reproducir, resultado esperado, resultado actual y evidencia de los incidentes encontrados.

## Herramientas y Técnicas
- Postman

## Resultado
Identificación y documentación de defectos funcionales relacionados con la validación de datos, los flujos de pedidos y el comportamiento esperado de la aplicación.
